# 🌍 Flashcards — Capitais do Mundo | Verdadeiro ou Falso

Jogo educativo no estilo **verdadeiro ou falso** sobre as capitais dos países do mundo. Desenvolvido para ser acessado diretamente no navegador, sem instalação ou dependências externas.

---

## 🎮 Como jogar

1. Leia a afirmação exibida no cartão
2. Clique em **✅ Verdadeiro** ou **❌ Falso**
3. Veja o gabarito com uma explicação sobre a capital correta
4. Avance para o próximo cartão
5. Ao final dos 50 cartões, confira seu resultado e porcentagem de acertos

---

## 🗺️ Regiões cobertas

| Região | Exemplos de países |
|---|---|
| Europa | Alemanha, Suíça, Noruega, Hungria, Polônia, Grécia |
| América do Sul | Brasil, Argentina, Colômbia, Equador, Uruguai |
| América do Norte | EUA, Canadá, México |
| América Central | Cuba, Guatemala |
| África | Quênia, Nigéria, Gana, África do Sul, Marrocos |
| Ásia | China, Japão, Índia, Turquia, Tailândia, Paquistão |
| Oceania | Austrália, Nova Zelândia |

---

## ✨ Funcionalidades

- 50 cartões com afirmações verdadeiras ou falsas
- Etiqueta de região em cada cartão
- Gabarito imediato com explicação educativa após cada resposta
- Barra de progresso animada
- Histórico visual de acertos 🟢 e erros 🔴 em tempo real
- Placar ao vivo (acertos e erros)
- Tela de resultado final com porcentagem, barra colorida e mensagem motivacional
- Cartões embaralhados a cada nova partida
- Botão para jogar novamente
