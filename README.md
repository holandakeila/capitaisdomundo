# 🌍 Flashcards — Capitais do Mundo | Verdadeiro ou Falso

Jogo educativo no estilo **verdadeiro ou falso** sobre as capitais dos países do mundo. Desenvolvido para ser acessado diretamente no navegador, sem instalação ou dependências externas.

---

## 🎮 Como jogar

1. Leia a afirmação exibida no cartão
2. Clique em **✅ Verdadeiro** ou **❌ Falso**
3. Veja o gabarito com uma explicação sobre a capital correta
4. Avance para o próximo cartão
5. Ao final dos 50 cartões, confira seu resultado e porcentagem de acertos

---

| Região | Exemplos de países |

---

## ✨ Funcionalidades

- 50 cartões com afirmações verdadeiras ou falsas
- Etiqueta de região em cada cartão
- Gabarito imediato com explicação educativa após cada resposta
- Barra de progresso animada
- Histórico visual de acertos 🟢 e erros 🔴 em tempo real
- Placar ao vivo (acertos e erros)
- Tela de resultado final com porcentagem, barra colorida e mensagem motivacional
- Cartões embaralhados a cada nova partida
- Botão para jogar novamente

---

## 🧠 Pegadinhas clássicas do jogo

O jogo inclui as confusões geográficas mais comuns, como:

- **Sydney** não é a capital da Austrália — é **Camberra**
- **Lagos** não é a capital da Nigéria — é **Abuja**
- **Zurique** não é a capital da Suíça — é **Berna**
- **Copenhague** não é a capital da Noruega — é **Oslo**
- **Istambul** não é a capital da Turquia — é **Ancara**
- **Bucareste** não é a capital da Bulgária — é **Sofia**
- **Kuala Lumpur** não é a capital da Indonésia — é **Jacarta**

## 🚀 Como publicar

### Opção 1 — GitHub Pages (recomendado)
1. Crie um repositório público no [github.com](https://github.com)
2. Faça upload do arquivo `index.html` via **Add file → Upload files**
3. Vá em **Settings → Pages → Branch: main → Save**
4. Aguarde 1-2 minutos — seu jogo estará em:
   ```
   https://seu-usuario.github.io/nome-do-repositorio
   ```

### Opção 2 — Netlify (arrastar e soltar)
1. Acesse [netlify.com](https://netlify.com) e crie uma conta gratuita
2. Vá em **Sites → Add new site → Deploy manually**
3. Arraste o arquivo `index.html` para a área de upload
4. Link público gerado instantaneamente

### Opção 3 — Teste local
Abra o arquivo `index.html` diretamente no navegador — funciona sem conexão com a internet.
